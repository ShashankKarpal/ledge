# ledge brand: Ink and Bone

This repository consumes Ink and Bone v1.1.0. The canonical definition and
the only generator live in `ShashankKarpal/shashankkarpal`, under
`design/brand/` and `design/marks/`.

Category: Copper, for capture and keep tools.

- The mark identifies the project. Category colour is a secondary cue and
  must never carry meaning by itself.
- Ink is the neutral, unaccented exception. It is not a fourth category.
- Use one category accent per mark. Status colours never double as category
  colours.
- Grain is the only texture. Do not use italics, emoji, or long dash
  punctuation.
- Inline text links keep a persistent underline in every interaction state.

This consumer contains only the live exports it uses and the generated
`design/BRAND-ASSETS.json` and `design/BRAND-ASSETS.md` provenance records.
It has no local generator, font kit, or complete output tree. Do not hand-edit
generated exports. Change the canonical source, regenerate there, and run the
canonical manifest-driven distributor.

The pre-2026-08 system this file used to describe is retired.
