# Ink and Bone mark pipeline

Every mark and every export in `out/` is generated by `generate_marks.py`. Nothing is hand-placed. Geometry is defined once per mark, on a 96 by 96 grid, stroke 7, round caps and joins, true arcs, with optically simplified variants for 24 and 16 pixels.

## Run

    python3 generate_marks.py              # everything
    python3 generate_marks.py helios zest  # specific projects

Dependencies: `pip install cairosvg pillow fonttools icnsutil`

## What each project gets

| Folder | Contents |
|---|---|
| `svg/` | mark.svg and mark-light.svg masters, mark-24 and mark-16 variants in both themes, mark-mono.svg |
| `pdf/` | mark.pdf (light palette, for print), mark-dark.pdf |
| `png/` | 1024 to 16, transparent in both palettes, on page #0B0C0D, on paper #F5F5F3 |
| `jpeg/` | 1024 and 512 on both grounds |
| `wordmark/` | horizontal and stacked lockups in Karpal Geometric, SVG, PDF, PNG, both themes |
| `macos/` | AppIcon.iconset, AppIcon.icns, menu bar `*-template.png` at 1x 2x 3x (black with alpha) |
| `ios/` | full AppIcon.appiconset with Contents.json, apple-touch-icon 180 |
| `watchos/` | watch AppIcon.appiconset, complications (circular, extra large, graphic corner, graphic circular) as white monochrome templates |
| `web/` | favicon.ico (16 32 48), favicon.svg (theme adaptive), README banners 1400x400 dark and light, social preview 1280x640, all with grain and category rail |
| `appstore/` | AppStore-1024.png, no alpha, no rounded corners |
| `contact-sheet-<project>.png` | one-glance review sheet (the unsuffixed `contact-sheet.png` name is legacy; the pipeline deletes it on rebuild) |

## Rules encoded here

Sizes 48 and up use the master geometry, 20 to 47 use the 24 variant, below 20 the 16 variant. One accent per mark, category colour only. Grain never behind small type; banners autoscale long names instead of clipping. Shields and label hexes stay in `../brand/brand-tokens.json`.

## macOS-only step

The `.icns` files are generated cross-platform by icnsutil. To rebuild natively on the Mac:

    iconutil -c icns out/<project>/macos/AppIcon.iconset -o AppIcon.icns

## Private

`out/private/` contains the monogram renders and `private_marks.py` holds its geometry. Both are gitignored here and exist only on Shanky's machines and in the private ink-and-bone mirror. Without `private_marks.py` this pipeline cannot render the monogram at all, by design. Never publish, link, or reference either. See `out/private/README-PRIVATE.md` and BRAND-SURFACES.md, INCIDENT 2026-08-19.
